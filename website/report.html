Report abuse

If you find a share link containing illegal, infringing, or otherwise terms-violating content, please report it using the channels below. The “Report abuse” entry on every download page leads here too. The no-signup sharing channel stopped accepting new uploads on 2026-10-20; existing links can still be reported until they expire naturally (within 24 hours), and this channel remains open.

What a report should include

1. The full URL of the share link (the complete URL starting with /s/ from the browser address bar);

2. A brief description of the violating content (what kind of illegal or infringing situation it involves);

3. For copyright matters, a statement of rights ownership helps.

No need to send the file itself; and please don’t post the share link itself in public channels (forums, social platforms, public repositories, etc.).

Contact

abuse@kodeoff.com

Stated as it is: this mailbox is being brought online; until real send/receive verification is complete and this page is updated, no fixed response-time commitment is made. The operator handles verified reports as soon as possible (process in section 2 of the terms).

Your privacy

A report needs only the information above: this page collects no reporter IP addresses, requires no login, and uses no third-party forms or analytics.

Report content is used solely for verification and takedown — for nothing else, and it is never shared with the reported party.
