No-signup sharing — paused

As of 2026-10-20, Kodeoff’s no-signup web sharing service is paused: this page no longer accepts new file uploads. Signed-in device transfer (the apps and the web inbox) is unaffected.

Existing share links

Links created earlier still work under the original rules: valid for 24 hours from creation and up to 20 downloads; on expiry, exhaustion of downloads or traffic quota, the file is deleted from the server automatically — no extensions, no recovery.

Reporting abuse

If an existing link contains illegal, infringing, or other terms-violating content, report it via the reporting guide or contact abuse@kodeoff.com. Reports and takedowns continue as usual during the natural expiry window of existing links.

Need to keep moving files

For files and clipboard between devices, use the Kodeoff apps or the web inbox (an account is required); for nearby devices, the system AirDrop works too.
