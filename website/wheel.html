01 · File actions

35+ actions,
right next to the file.

Three entrances lead to the same menu: pause while dragging, hold Shift with the file selected, or right-click in Finder. What shows up in the menu is decided by the type of file you selected — everything runs locally, nothing is uploaded.

File action guide →

Three entrances, one menu

Pause while dragging, hold Shift after selecting, or dive in from the Finder context menu — all three open the same radial menu. Its actions are generated on the fly based on the selected file type: pick an image and conversion actions appear, pick text and an editor appears. Actions can be shown, hidden, or rearranged by dragging, and the pause duration that triggers the menu is adjustable.

17 format conversions and image tools

CSV encoding conversion (GBK↔UTF-8), SRT↔VTT, JSON↔CSV, six-way image conversion with PDF output, PNG→ICO/ICNS, MP4→GIF, MP3→M4R ringtones and more; plus image compression, proportional scaling, 1:1/16:9/4:3/3:4 center crops, and metadata stripping (including GPS). Results are saved next to the original with a suffix, and the original is kept.

Finder context menu

Create text, Markdown, XML, RTF, Word, Excel, or PPT files in empty space; with files selected, move, copy, cut, or copy file names, send to your phone, or share a link — all from the right-click menu. Frequently used folders can be saved as move/copy targets.

The Finder extension needs to be enabled on first use. Inside iCloud Drive and other cloud folders, use Services → “Open Kodeoff radial menu” instead.

Set it up your way

Drag actions to rearrange the wheel, turn off menu items and sub-menu actions you don’t need, and switch between glass, light, or dark. The trigger pause duration and radius are adjustable too.

Selection & eight annotation tools

Drag a region or click a recognized window, with a magnifier for precise positioning and arrow keys for 1-pixel nudges. Rectangle, ellipse, arrow, text, pen, auto-numbering, mosaic, and eraser, with undo and redo; 3-second and 5-second delayed captures too.

Pinning, outputs & history

In the annotation editor, one click pins the image with its annotations as a desktop sticker, and you can pin several in a row; stickers can be dragged, zoomed with the scroll wheel, and made translucent with ⌘+scroll. Esc closes one sticker, ⌘⇧Esc collapses all. The default after-capture action is copy to clipboard; the preview panel offers save, send, and share outputs with 100% original-pixel viewing. Screenshot history stays on this Mac only — 30 entries by default, adjustable or off.

Requires the screen-recording permission; selection is limited to the screen where it started (no cross-screen stitching yet). The auto-send-to-phone switch is documented on the Device transfer page.

03 · Platform limits

Check the boundaries
before you download.

The two desktop platforms are at different levels of completeness — stated as they are.

Go to downloads →

macOS: fully featured, unsigned & unnotarized

File radial menu, screenshot pinning, and cross-device transfer all work. The public preview is ad-hoc signed and not yet notarized with a Developer ID; on first launch right-click → “Open”.

Windows: experimental subset

The basics of the local radial menu: seven core actions plus convert to JPG/PNG/MP4, with a settings page shared with macOS (HEVC→H.264 needs the “HEVC Video Extensions”). No screenshots, signed-in transfer, or AirDrop; not yet validated on a real Windows machine. Unzip the whole ZIP before running; SmartScreen may appear on first run.
