你可能还想知道

常见问题。

需要授予什么权限？

不需要辅助功能权限。Kodeoff 使用系统公开 API 识别文件拖拽与停顿，并将轮盘作为拖放目标。文件访问仍遵循系统的权限设置。

什么时候可以下载？收费吗？

v0.1.3 预发布已上线，DMG / ZIP 可从 Releases 下载。代码不开源，授权与收费方案会在正式版发布时公布。

如何取消一次操作？

把光标移回轮盘中心再松手，或将文件拖出轮盘边界。Finder 拖拽本身也可通过 Esc 取消。

Windows 版现在能用吗？

x64 构建版已产出，面向 Windows 10+，但尚未经真机验证，拖拽检测与动作执行仍待确认。ZIP 已随 v0.1.3 预发布提供（同样未真机验证）。

发送到手机必须登录 iCloud 吗？

iCloud 通道需要两端登录同一 Apple ID，并使用携带 iCloud entitlement 的正式构建；该通道与 iOS 收件端尚未经真机验证。附近设备可使用 AirDrop，自托管通道的应用内接入仍在进行。
