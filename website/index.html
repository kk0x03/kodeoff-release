本地文件操作与截图

复制路径、编辑和新建等本地动作不联网。截图需要屏幕录制权限，历史保存在本机；已登录且开启截图自动同步时，完成并复制的截图会上传到中继。可选的 Finder 长按入口另需辅助功能权限。

在线发送与分享

当前中继传输与存储不提供端到端加密，服务器可访问其存储的文件与元数据。官方服务使用 HTTPS；自建服务跨网络使用也需要 HTTPS。

加密信封已实现、通道接入进行中；端到端加密尚未上线，不宣称「仅你可读」。

macOS 13+（Apple Silicon）

功能最完整的平台：文件轮盘、截图钉图与跨设备收发。公开预览包使用 ad-hoc 签名，尚未完成 Developer ID 签名和公证；首次打开请右键→「打开」。

Windows 10+（x64）

本地轮盘的基础体验：七项基础动作加转 JPG/PNG/MP4，设置页与 macOS 共用（HEVC→H.264 需系统装有「HEVC 视频扩展」）。为实验性构建：不含截图、登录收发与 AirDrop，尚未经 Windows 真机验收；ZIP 需完整解压后运行，首次运行可能遇到 SmartScreen 提示。

常见问题

按功能查阅完整使用说明

哪些功能不需要登录？ ＋

本地文件操作与格式转换、截图、保存、贴图与 AirDrop 不需要中继账号。设备收发和应用内创建分享链接需要登录；网页免登录分享通道已于 2026-10-20 暂停新上传，应用内分享不受影响。35+ 个本地动作的完整清单见轮盘桌面工具页。

会自动上传我的剪贴板吗？ ＋

普通文本只在你选择「发送剪贴板到手机」时发送。截图有独立的自动同步开关，默认开启：登录后，截图完成并复制时会上传。可在「设置 → 截图」关闭。

Finder 右键菜单没有出现？ ＋

先把 Kodeoff 放入「应用程序」并完成首次打开，再到系统设置启用 Finder 扩展。iCloud Drive 等云目录内改用「服务 → 用 Kodeoff 打开轮盘」。查看启用与排查步骤。

需要什么系统权限？ ＋

拖拽呼出轮盘无需辅助功能权限；截图需要屏幕录制权限；左 Shift 呼出与 Finder 长按入口需要辅助功能权限。文件访问遵循 macOS 的权限设置。

Android 客户端怎么安装？ ＋

v0.1.9 起 Android 收件端 APK 在 GitHub Release 页提供，为 debug 签名的侧载包：安装需开启「允许安装未知来源应用」，且不可与未来的商店签名版共存。登录中继账号后即可收发与同步；App 在前台时轮询同步，不在前台时消息在下次打开时到达。
