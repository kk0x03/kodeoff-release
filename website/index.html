01 · 文件操作

35+ 个动作，
就在文件旁边。

拖住文件停一下出轮盘，选中文件后按住 Shift 呼出，或从 Finder 右键菜单直达——格式转换、压缩、裁剪与日常操作全部本地执行，零上传。

文件操作使用说明 →

三个入口，一个动作面

拖住文件停一下、选中后按住 Shift、或从 Finder 右键菜单直达——三个入口通向同一个轮盘。转格式 / 文件工具 / 文件动作三条支路按所选文件类型现算菜单，动作可显隐、可拖放自定义，触发的停顿时长也可调整。

17 项格式转换与图片工具

CSV 编码互转（GBK↔UTF-8）、SRT↔VTT、JSON↔CSV、图片六格式互转并可出 PDF、PNG→ICO/ICNS、MP4→GIF、MP3→M4R 铃声等；另有压缩图片、等比缩放、1:1/16:9/4:3/3:4 居中裁剪与去元数据（含 GPS）。结果存原文件旁、命名加后缀，原文件保留。

Finder 右键菜单

在空白处新建文本、Markdown、XML、RTF、Word、Excel 或 PPT 文件；选中文件后移动、拷贝、剪切或复制文件名，发送到手机与分享链接右键直达。常用目录可保存为移动与拷贝的目标。

首次使用需启用 Finder 扩展。iCloud Drive 等云目录内请改用「服务 → 用 Kodeoff 打开轮盘」。

按自己的习惯设置

拖放动作调整轮盘，关闭不需要的菜单项与支路动作，切换毛玻璃、浅色或深色。触发停顿时长与半径也可调整。

选区与八种标注工具

框选或点击窗口，放大镜辅助定位，方向键按 1 像素微调。矩形、椭圆、箭头、文字、画笔、序号、马赛克和橡皮擦，支持撤销与重做；也可延迟 3 秒或 5 秒截图。

钉图、出口与历史

标注编辑器里一键把底图连同已画标注钉为桌面贴图，可连续钉多张；贴图可拖动、滚轮缩放、⌘+滚轮调透明度，Esc 收单张、⌘⇧Esc 收全部。默认截后动作是复制到剪贴板；预览面板提供保存、发送与分享出口，支持原始像素 100% 查看。截图历史仅存在本机，默认 30 张，可调整保留数量或关闭。

需要屏幕录制权限；选区限定在起始屏幕内，暂不支持跨屏拼接。截图自动发送的开关见下一组「设备收发」。

03 · 跨设备收发

文件与剪贴板，
在你的设备间传递。

登录同一账号，文件、文件夹与剪贴板在 Mac、iPhone、Android 与浏览器之间收发。

打开网页收件箱 →
Mac文件 · 文本 · 截图→中继服务→手机 / 网页收件箱

发送文件与文件夹

通过轮盘或右键菜单发送单个文件；文件夹自动压缩为 ZIP，预扫、压缩与上传分阶段显示进度，超过阈值（默认 500 MB，100–2048 MB 可调）会在压缩开始前弹出确认：大小、文件数与预计耗时，取消则整条链路不入队。接收端下载后可预览，文件与缓存由各端分别管理。

手动发送剪贴板文本

从 Mac 菜单栏选择「发送剪贴板到手机」，可发送文字和链接。单次最多 64 KiB，超限会提示，不截断内容；普通文本不会在后台自动同步。

截图后自动发送

完成截图并复制后，可自动发送到手机收件箱的剪贴板栏。此开关默认开启，可在「设置 → 截图」关闭；未登录时跳过发送。每台发送设备只保留最新一张自动同步截图，上传失败会保留上一张。

Android 收件端（v0.1.9 新增）

邮箱或账号码登录，配对码绑定设备；收件箱接收文本与图片投递，增量同步、下载逐条 SHA256 校验；链接页可查看自己的分享列表并撤销；还能发送剪贴板图片。App 在前台时轮询同步，不在前台时消息在下次打开时到达。

附近设备也可用 AirDrop

Mac 上可调用系统隔空投送，支持多选文件，无需 Kodeoff 中继账号。

收发经登录账号的中继服务进行：可用官方服务（注册需邀请码）或自建服务，需要网络；端到端加密尚未上线。iOS 与 Android 收件端在 App 打开时自动同步（Android 为前台轮询，无后台推送），网页收件箱前台刷新。

本地文件操作与截图

复制路径、编辑和新建等本地动作不联网。截图需要屏幕录制权限，历史保存在本机；已登录且开启截图自动同步时，完成并复制的截图会上传到中继。可选的 Finder 长按入口另需辅助功能权限。

在线发送与分享

当前中继传输与存储不提供端到端加密，服务器可访问其存储的文件与元数据。官方服务使用 HTTPS；自建服务跨网络使用也需要 HTTPS。

加密信封已实现、通道接入进行中；端到端加密尚未上线，不宣称「仅你可读」。

macOS 13+（Apple Silicon）

功能最完整的平台：文件轮盘、截图钉图与跨设备收发。公开预览包使用 ad-hoc 签名，尚未完成 Developer ID 签名和公证；首次打开请右键→「打开」。

Windows 10+（x64）

本地轮盘的基础体验：七项基础动作加转 JPG/PNG/MP4，设置页与 macOS 共用（HEVC→H.264 需系统装有「HEVC 视频扩展」）。为实验性构建：不含截图、登录收发与 AirDrop，尚未经 Windows 真机验收；ZIP 需完整解压后运行，首次运行可能遇到 SmartScreen 提示。

常见问题

按功能查阅完整使用说明

哪些功能不需要登录？ ＋

本地文件操作与格式转换、截图、保存、贴图与 AirDrop 不需要中继账号。设备收发和应用内创建分享链接需要登录；网页免登录分享通道已于 2026-10-20 暂停新上传，应用内分享不受影响。

会自动上传我的剪贴板吗？ ＋

普通文本只在你选择「发送剪贴板到手机」时发送。截图有独立的自动同步开关，默认开启：登录后，截图完成并复制时会上传。可在「设置 → 截图」关闭。

Finder 右键菜单没有出现？ ＋

先把 Kodeoff 放入「应用程序」并完成首次打开，再到系统设置启用 Finder 扩展。iCloud Drive 等云目录内改用「服务 → 用 Kodeoff 打开轮盘」。查看启用与排查步骤。

需要什么系统权限？ ＋

拖拽呼出轮盘无需辅助功能权限；截图需要屏幕录制权限；左 Shift 呼出与 Finder 长按入口需要辅助功能权限。文件访问遵循 macOS 的权限设置。

Android 客户端怎么安装？ ＋

v0.1.9 起 Android 收件端 APK 在 GitHub Release 页提供，为 debug 签名的侧载包：安装需开启「允许安装未知来源应用」，且不可与未来的商店签名版共存。登录中继账号后即可收发与同步；App 在前台时轮询同步，不在前台时消息在下次打开时到达。
