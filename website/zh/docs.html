01 · 文件操作

在文件上打开轮盘

在 Finder 中拖住文件，光标停顿后出现轮盘。移动到动作扇区并松手执行；移回盘心或离开轮盘取消。

不想拖动时，可以在 Finder 文件的右键菜单中选择「服务 → 用 Kodeoff 打开轮盘」。首次安装后若服务项还未出现，可重新登录 macOS 后再检查。

v0.1.7 已提供可选的 Finder 长按入口：设置 → 操作习惯 → 打开轮盘开启（默认关闭），需授权辅助功能，尚未经真机全面验证；无需为普通拖拽入口额外授权。Finder 右键菜单的启用方式见下一节。

Finder 右键菜单

把 Kodeoff 放入「应用程序」并完成首次打开，然后到「系统设置 → 通用 → 登录项与扩展 → 访达扩展」启用 Kodeoff。部分系统版本位于「系统设置 → 扩展 → 添加的扩展」。首次启动也会显示引导。

在空白处可新建七种格式的文件、复制当前目录路径或粘贴剪切项；选中文件后可复制路径与文件名、移动、拷贝、剪切、发送、分享或打开轮盘。到「设置 → 菜单动作」调整显隐与常用目录。

iCloud Drive、OneDrive 等云目录可能不显示此扩展菜单，可使用「服务 → 用 Kodeoff 打开轮盘」。升级后菜单仍未出现，可重启 Finder 后再检查。

直接在轮盘上自定义

打开设置中的轮盘自定义页，把可用动作拖到目标扇区上即可替换。点击扇区查看当前动作及其配置；空位也可以接收拖入的动作。

轮盘默认使用毛玻璃，可在外观设置中切换浅色或深色。触发停顿时长与半径控制轮盘出现的时机。

02 · 截图标注

开始截图与选择区域

默认快捷键为 ⌥ ⌘ 4，也可从菜单栏选择「屏幕截图」。第一次使用需在系统设置授权屏幕录制；设置 → 截图可更换快捷键。

拖拽框选区域，或点击识别到的窗口。方向键按 1 像素移动选区，⌘+方向键调整单边；Esc 取消。菜单栏另有 3 秒与 5 秒延迟截图。

选区限定在起始显示器内，暂不支持跨屏拼接。显示环境为低分辨率或虚拟屏时会给出提示，可到系统显示设置检查。

标注与完成

选择矩形、椭圆、箭头、文字、画笔、序号、马赛克或橡皮擦。⌘Z 撤销、⌘⇧Z 重做。文字输入时回车完成文字，再确认整张截图。

默认完成后复制到剪贴板。若需要每次停留查看，可在「设置 → 截图」把截后动作改为预览面板：支持保存 PNG、复制、发送、分享链接与贴图；点击「原始像素 100%」检查细节，大图可滚动查看。

贴图与本机历史

贴图以小窗留在桌面上，可拖动位置、滚轮缩放、⌘+滚轮调整透明度。Esc 关闭当前贴图，⌘⇧Esc 收起全部；全局快捷键被占用时会提示。

菜单栏「截图历史…」可预览、复制、重发、分享或删除。默认保留最近 30 张，设置中可调整为 10–200 张或关闭；关闭会立即清空本机历史。

登录后，截图默认还会自动发送到手机。关闭自动上传的方式见剪贴板与截图同步。

03 · 设备收发

账号与设备

使用邮箱和密码登录，忘记密码时可通过邮件验证码重置。官方服务已启用真实验证码邮件；请同时查看收件箱和垃圾邮件。未启用邮件的自建服务可使用账号码或配对码添加设备。

iOS 商店与 TestFlight 构建内置官方 HTTPS 服务，普通用户无需填写服务器地址。当前官方服务使用邀请码注册：创建账号需要有效邀请码，并通过邮箱验证码验证；已有账号可直接使用邮箱和密码登录。专用开发构建可以连接本地测试服务。

账号码可让新设备加入账号，请像密码一样保管。配对码为短期有效的一次性凭据。设备登录后会获得独立凭据，可从设备列表移除不再使用的设备。

发送文件与文件夹

在 Mac 轮盘中选择「发送到手机」，或从 Finder 右键菜单发送。文件夹会自动压缩为 ZIP；多选时中继发送动作不可用，可先压缩为一个文件。两端需登录同一中继服务的同一账号。

附近的 Apple 设备可选择 AirDrop，支持多选文件，无需中继账号。

剪贴板与截图同步

普通文本与链接需要从 Mac 菜单栏手动选择「发送剪贴板到手机」。单次最多 64 KiB，超限拒绝发送，不会截断；空内容、被标记为敏感的剪贴板与文件引用不会按普通文本发送。

截图有独立的自动同步开关，位于「设置 → 截图」，默认开启。登录中继后，完成并复制的截图会发送到手机收件箱的剪贴板栏；未登录时跳过。每台发送设备仅保留最新一张自动同步截图，新上传失败时不会删除上一张。

不想自动上传截图时，关闭「截图后自动同步剪贴板」。本地复制、保存与手动发送入口仍然可用。

收件、缓存与退出

iOS 与网页收件箱展示当前账号的文件、剪贴板文本与截图。点击文件可下载并预览；下载策略和缓存保留天数可在设置中调整。

当前中继通道在 App 打开时自动刷新。切到后台后不会发送新文件通知；回到 App 后同步新内容。

退出登录会清除本机登录状态和该账号的收件缓存，并尝试吊销当前设备；不会删除服务器上供其他设备使用的文件。离线退出后，可从其他设备确认并移除旧设备。

macOS 凭据保存在本机固定文件中，不读取钥匙串。iOS 使用系统钥匙串；网页使用浏览器本地存储。切换服务不会把旧服务凭据发送到新服务。

04 · 链接分享

从 App 创建分享链接

登录中继账号后，在 Finder 右键菜单选择「分享链接」，或从截图预览、截图历史窗口创建。上传成功会复制链接并显示有效时间；接收方无需你的账号，用浏览器打开即可下载。

链接的有效时间与剩余下载次数以实际下载页为准。任何持有有效链接的人都可以下载，请勿向不可信的人转发。

网页免登录分享（已暂停）

该通道已于 2026-10-20 暂停：免登录分享页停止接受新的文件上传。此前生成的链接仍按原规则在 24 小时内有效、最多下载 20 次，到期或次数用尽后自动删除。

如发现既有链接包含违规内容，请经举报指引页反馈。

安装、权限与排查

遇到问题

连接失败时，先检查服务是否运行、设备能否访问该地址、HTTPS 证书及本地网络权限。登录失败时确认账号属于当前服务；重置密码会使旧设备登录失效。

Windows 目前为实验性本地轮盘构建，尚未接入手机收发；截图目前仅在 macOS 提供；iOS 接收端需单独获取构建。iCloud 通道已退役。

可在 反馈页提供平台、版本、复现步骤及错误提示。请勿提交密码、账号码、配对码、凭据文件或私人文件。

自建服务说明 ＋

自建服务

自建中继适合自行管理服务器的用户。服务端位于开发仓库的 server/；本机开发可运行 bash server/run-dev.sh，使用临时数据目录。专用开发或自建构建可单独启用连接配置，默认用户界面不展示该配置。

本机回环地址只能由服务器所在电脑访问，手机不能通过它连接另一台电脑。真机联调需在构建中配置可达地址；跨网络服务需要 HTTPS、持久数据目录、邮件配置及备份恢复验证。

中继目前未接入端到端加密。服务器可以读取存储的内容；不要把临时开发实例当作已验收的生产服务。
